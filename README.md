# Cifra – Prototipos · Metafields (Polaris Web Components 2.0-rc)

Copia de [cifra-prototipos](https://github.com/jesusavendano-web/cifra-prototipos) para diseñar **ENG-2310 · Incluir metafields en Cifra** (solo front).

Pantallas nuevas o tocadas:

- `settings.html#metafields` – nueva pestaña en Settings: resumen por recurso (Products, Variants, Orders, Customers) y estado de sync.
- `settings-metafields.html` – tabla por recurso para activar cada definición de metafield (+ tabla de tipos soportados).
- `report-metafields.html` – reporte usando un metafield como dimensión y como filtro; picker de dimensiones con metafields dentro de su recurso.

Local: `node serve.js` → http://localhost:4321
